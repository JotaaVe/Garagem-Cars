# Imagens da apresentação

Capturas do APK Android fornecidas pelo proprietário para a apresentação do Garagem Cars, junto da logo Rust-eze utilizada no aplicativo.

As capturas mostram uma coleção cadastrada; seus itens, fotos e valores não são um catálogo incluído no app. Os arquivos originais foram preservados.

Marcas, personagens e logos pertencem aos respectivos titulares.
